CONTINUOUS DIFFUSION LANGUAGE MODELS FOR DUMMIES
Apple-style HTML publishing package

Open index.html in a modern browser to read the complete article offline.
Open zh.html for the complete Chinese edition. Both pages provide a
language switch that retains the current section when JavaScript is enabled.
Keep the assets folder beside index.html.

To publish, upload index.html and the assets folder together to a static
website host. No build step, JavaScript framework, external font service,
or CDN is required. All mathematical notation uses native MathML.

The old private-preview canonical URL and og:url metadata have been removed.
The article now shares the homepage's white/gray palette, system sans-serif
typography, blue accents, translucent navigation, and rounded diagram cards.

This folder is the editable source. The homepage entry is configured in
content/posts.json at the repository root. Run the repository build to copy
the article and its assets into dist/posts/cdlm-for-dummies/. The build also
adjusts the return-home links for that destination. Distribute the complete
dist folder so the homepage, article, and supporting assets stay together.

This is Part 1 of a four-part series. Parts 2–4 are still in progress.
The Chinese page translates the text, contents, captions, tables, controls,
and accessibility labels while retaining the original MathML and examples.

The finalized article wording, headings, equations, captions, checklist,
references, and sign-off are preserved. The additions are presentation:
responsive layout, contents navigation, a redrawn generation diagram with
optional playback, a two-city probability diagram, and figure enlargement.
Animations do not autoplay. A static version remains readable without JavaScript.
